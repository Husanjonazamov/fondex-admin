QADAM 1 — Vehicle Type olish

Collection: vehicle_type
Filtr: where('sectionId', isEqualTo: currentSectionId) 
QuerySnapshot types = await FirebaseFirestore.instance
    .collection('vehicle_type')
    .where('sectionId', isEqualTo: currentSectionId)
    .get();

// Dropdown uchun:
// value = doc['id']     → "vt_001"
// label = doc['name']   → "Comfort"

// Saqlab qo'yish:
String selectedVehicleTypeId = doc['id'];       // "vt_001"
String selectedVehicleTypeName = doc['name'];   // "Comfort"

QADAM 2 — Car Make olish (Vehicle Type bo'yicha)

Collection: car_model
Filtr: where('vehicle_type_id', isEqualTo: selectedVehicleTypeId)
Natija: Noyob car_make_id va car_make_name larni ajratish 
QuerySnapshot models = await FirebaseFirestore.instance
    .collection('car_model')
    .where('vehicle_type_id', isEqualTo: selectedVehicleTypeId)
    .get();

// Noyob brendlarni ajratish:
Set<String> usedMakeIds = {};
List<Map<String, String>> makesList = [];

for (var doc in models.docs) {
  String makeId = doc['car_make_id'];
  String makeName = doc['car_make_name'];

  if (!usedMakeIds.contains(makeId)) {
    usedMakeIds.add(makeId);
    makesList.add({'id': makeId, 'name': makeName});
  }
}

// makesList = [{id: "mk_001", name: "Chevrolet"}, ...]
// Faqat tanlangan tarifga tegishli brendlar!

// Saqlab qo'yish:
String selectedCarMakeId = tanlangan['id'];      // "mk_001"
String selectedCarMakeName = tanlangan['name'];  // "Chevrolet"

QADAM 3 — Car Model olish (Vehicle Type + Make bo'yicha)

Collection: car_model
Filtr: where('vehicle_type_id' == ...) + where('car_make_id' == ...) 
QuerySnapshot filteredModels = await FirebaseFirestore.instance
    .collection('car_model')
    .where('vehicle_type_id', isEqualTo: selectedVehicleTypeId)
    .where('car_make_id', isEqualTo: selectedCarMakeId)
    .get();

// filteredModels = [Malibu 2, Captiva, ...]
// Faqat tanlangan tarif + brend ga tegishli modellar!

// Saqlab qo'yish:
String selectedCarModelName = doc['name'];  // "Malibu 2"

QADAM 4 — Saqlash (users collection)

Collection: users
Amal: doc(uid).set({...}) 
await FirebaseFirestore.instance.collection('users').doc(uid).set({
  'id': uid,
  'firstName': firstName,
  'lastName': lastName,
  'email': email,
  'phoneNumber': phone,
  'role': 'driver',
  'serviceType': 'cab-service',
  'sectionId': sectionId,

To'liq Jarayon

1. vehicle_type → where('sectionId' == ...) → id, name
↓
2. car_model → where('vehicle_type_id' == ...) → noyob car_make_id, car_make_name
↓
3. car_model → where('vehicle_type_id' == ...) + where('car_make_id' == ...) → name
↓
4. users → doc(uid).set({...})
❗ MUHIM: Agar car_model hujjatlarida vehicle_type_id fieldi bo'lmasa, admin paneldan Car Model bo'limiga kirib, har bir modelga Vehicle Type biriktirish kerak. Bu fieldni admin panel avtomatik saqlaydi.
